# Sigelith Desktop — ru-ru

## Short description
Отмечайте файлы, не загружая их, проверяйте любое доказательство офлайн, следите за независимыми свидетелями публичного журнала — и передавайте файлы с доказательством передачи. Бесплатно, без аккаунта, с открытым кодом.

## Description
Sigelith Desktop доказывает, что файл существовал в определённый момент, — а сам файл никогда не покидает ваш компьютер.

Отметка файлов
Перетащите файлы в окно. Приложение вычисляет хеш SHA-256 каждого файла на вашем компьютере и отправляет в публичный журнал Sigelith только этот хеш. Вы получаете PDF-сертификат и офлайн-доказательство .beatproof.

Проверка без доверия к нам
Перетащите любой файл, чтобы узнать, отмечен ли он и когда. Приложение само проверяет путь включения и подпись — ключами, встроенными в программу. В приватном режиме оно хранит собственную копию публичного журнала, поэтому сервер никогда не узнаёт, какой файл вы проверяете.

Свидетели
Пока приложение работает, оно само проверяет журнал: подписанные контрольные точки, цепочку между ними, копии на GitHub, в Internet Archive и Zenodo, а также названные в них блоки Bitcoin. Любое расхождение вызывает тревогу.

Передавайте файлы с доказательством передачи
Получатель подтверждает получение собственным ключом (Windows Hello), а момент передачи записывается в публичный журнал. Отправление идёт между вами; сервер Sigelith ничего не хранит.
Для тех, у кого нет проверяющей программы, — юриста, эксперта, суда: откройте доказательство через «Проверить доказательство…» и сохраните PDF-отчёт — каждая проверка словами, с инструкцией для независимой проверки.
Если отправление не открывается так, как было предложено, принятие получателя не имеет силы. Приложение сообщает об этом и сохраняет доказательство дефекта, которое любой может пересчитать.

Приватно по умолчанию
Приватный режим хранит копию всего публичного журнала (только хеши, которые и так публичны), поэтому обновление доказательства никогда не сообщает серверу, какое из них ваше.

Что доказывает отметка времени
Отметка времени показывает, что файл именно с этими байтами существовал не позднее записанного момента. Она не показывает, кто создал файл и что он означает. Доказательство привязано к точным байтам. Копия, заново сохранённая редактором или пережатая мессенджером, имеет другой хеш — храните оригинал вместе с его сертификатом.

Sigelith Desktop бесплатен и имеет открытый код (Apache-2.0). Без аккаунта, без рекламы, без телеметрии.
Доступно на английском, польском, немецком, испанском, французском, русском, турецком, японском, корейском, китайском и арабском.

## What's new in this version
• Проверяет доказательства времени для отдельных файлов из Sigelith Backup (файлы .sigelith-proof): доказательство показывает, что файл был в запечатанной резервной копии в тот момент, не раскрывая остальные файлы.
• Двойной щелчок по файлу .beatproof или .sigelith-proof открывает приложение на вкладке «Проверка» — файл доказательства никогда не будет отмечен по ошибке.
• Sigelith Backup может передать файл из копии прямо в Sigelith Handover.
