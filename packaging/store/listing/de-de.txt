# Sigelith Desktop — de-de

## Short description
Versieh Dateien mit Zeitstempel, ohne sie hochzuladen, prüfe jeden Nachweis offline, behalte die unabhängigen Zeugen des öffentlichen Logs im Blick — und übergib Dateien mit Übergabenachweis. Kostenlos, ohne Konto, quelloffen.

## Description
Sigelith Desktop weist nach, dass eine Datei zu einem bestimmten Zeitpunkt existierte — und die Datei verlässt deinen Computer nie.

Dateien stempeln
Zieh Dateien auf das Fenster. Die App berechnet den SHA-256-Hash jeder Datei auf deinem Computer und sendet nur diesen Hash an das öffentliche Sigelith-Log. Du bekommst ein PDF-Zertifikat und einen Offline-Nachweis .beatproof.

Prüfen, ohne uns zu vertrauen
Leg eine beliebige Datei ab, um zu sehen, ob und wann sie gestempelt wurde. Die App prüft den Einschlusspfad und die Signatur selbst — mit Schlüsseln, die im Programm eingebaut sind. Im privaten Modus hält sie eine eigene Kopie des öffentlichen Logs, sodass der Server nie erfährt, welche Datei du prüfst.

Zeugen
Solange die App läuft, prüft sie das Log selbst: signierte Checkpoints, die Kette dazwischen, Kopien bei GitHub, im Internet Archive und bei Zenodo sowie die darin genannten Bitcoin-Blöcke. Jede Abweichung löst einen Alarm aus.

Dateien mit Übergabenachweis übergeben
Der Empfänger bestätigt den Erhalt mit seinem eigenen Schlüssel (Windows Hello), und der Zeitpunkt der Übergabe wird im öffentlichen Log erfasst. Die Sendung reist zwischen euch; der Sigelith-Server speichert nichts.
Für Lesende ohne Prüfprogramm — Rechtsvertretung, Sachverständige, Gericht: Öffne den Nachweis mit „Nachweis prüfen…“ und speichere einen PDF-Bericht — jede Prüfung in Worten, mit einer Anleitung zur unabhängigen Prüfung.
Lässt sich eine Sendung nicht so öffnen, wie sie angeboten wurde, ist die Annahme des Empfängers wirkungslos. Die App sagt das und speichert einen Fehlernachweis, den jeder nachrechnen kann.

Standardmäßig privat
Der private Modus hält eine Kopie des gesamten öffentlichen Logs (nur Hashes, die ohnehin öffentlich sind), sodass das Aktualisieren eines Nachweises dem Server nie verrät, welcher deiner ist.

Was ein Zeitstempel beweist
Ein Zeitstempel zeigt, dass eine Datei mit genau diesen Bytes spätestens zum erfassten Zeitpunkt existierte. Er zeigt nicht, wer die Datei erstellt hat oder was sie bedeutet. Der Nachweis hängt an genau diesen Bytes. Eine Kopie, die ein Editor neu gespeichert oder ein Messenger neu komprimiert hat, hat einen anderen Hash — behalte das Original zusammen mit seinem Zertifikat.

Sigelith Desktop ist kostenlos und quelloffen (Apache-2.0). Kein Konto, keine Werbung, keine Telemetrie.
Verfügbar auf Englisch, Polnisch, Deutsch, Spanisch, Französisch, Russisch, Türkisch, Japanisch, Koreanisch, Chinesisch und Arabisch.

## What's new in this version
• Neues App-Symbol: der Sigelith-Ring mit Häkchen.
• Mehrere Dateien auf einmal: Nach dem Stempeln eines Durchgangs speichern die Schaltflächen „PDF-Zertifikate“ und „Offline-Nachweise“ für jede Datei des Durchgangs ein Zertifikat bzw. einen .beatproof-Nachweis in einem Ordner deiner Wahl. Bisher geschah das nur für die letzte Datei.
• Verlauf: Markiere mehrere Einträge, um für jeden ein Zertifikat oder einen Nachweis zu speichern.
• Beim Speichern mehrerer Dateien wird nichts überschrieben: Ist ein Name schon vergeben, bekommt die neue Datei eine Nummer, und eine Übersicht zeigt, wie viele Dateien gespeichert wurden.
