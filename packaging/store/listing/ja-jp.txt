# Sigelith Desktop — ja-jp

## Short description
ファイルをアップロードせずにタイムスタンプを付与し、どんな証明もオフラインで検証し、公開ログの独立した証人を見守り、引き渡しの証明付きでファイルを渡せます。無料、アカウント不要、オープンソース。

## Description
Sigelith Desktop は、ファイルがある時点に存在したことを証明します。ファイル自体がコンピューターの外に出ることはありません。

ファイルにタイムスタンプを付与
ファイルをウィンドウにドラッグします。アプリはあなたのコンピューター上で各ファイルの SHA-256 ダイジェストを計算し、Sigelith の公開ログにはそのダイジェストだけを送ります。PDF 証明書とオフライン証明 .beatproof が手に入ります。

私たちを信頼せずに検証
任意のファイルをドロップすると、タイムスタンプの有無と時刻がわかります。アプリはプログラムに組み込まれた鍵を使って、包含パスと署名を自分で確認します。プライベートモードでは公開ログの独自コピーを保持するため、どのファイルを確認しているかがサーバーに知られることはありません。

証人
アプリは動作中、ログを自分で監査します: 署名済みチェックポイント、その間のチェーン、GitHub・Internet Archive・Zenodo のコピー、そこに記された Bitcoin ブロック。食い違いがあれば警告します。

引き渡しの証明付きでファイルを渡す
受取人は自分の鍵（Windows Hello）で受領を確認し、引き渡しの時刻は公開ログに記録されます。送付物は当事者間を移動し、Sigelith のサーバーは何も保管しません。
検証ツールを持たない相手（弁護士、鑑定人、裁判所）には、「証拠を確認…」で証拠を開き、PDF レポートを保存してください。すべてのチェックが平易な言葉で示され、独立して確認するための手順も含まれます。
送付物が申し出どおりに開かない場合、受取人の受諾は効力を持ちません。アプリはそれを知らせ、誰でも再計算できる欠陥の証拠を保存します。

標準でプライベート
プライベートモードは公開ログ全体のコピー（もともと公開されているダイジェストだけ）を保持するため、証明を更新しても、どれがあなたのものかがサーバーに知られることはありません。

タイムスタンプが証明すること
タイムスタンプは、まったく同じバイト列のファイルが記録された時刻までに存在していたことを示します。誰がそのファイルを作成したか、何を意味するかは示しません。 証明はまったく同じバイトに結び付いています。エディターで保存し直したり、メッセンジャーで再圧縮されたりしたコピーはダイジェストが異なります。元のファイルを証明書と一緒に保管してください。

Sigelith Desktop は無料のオープンソースです（Apache-2.0）。アカウント不要、広告なし、テレメトリーなし。
英語、ポーランド語、ドイツ語、スペイン語、フランス語、ロシア語、トルコ語、日本語、韓国語、中国語、アラビア語に対応しています。

## What's new in this version
• 新しいアプリ アイコン：チェックマーク付きの Sigelith リング。
• 複数ファイルをまとめて：バッチにタイムスタンプを付けたあと、［PDF 証明書］と［オフライン証明］のボタンで、バッチ内のすべてのファイルの証明書または .beatproof 証明を、選んだフォルダーに保存します。これまでは最後のファイルの分だけでした。
• 履歴：複数のエントリを選ぶと、それぞれの証明書または証明を保存できます。
• 複数のファイルを保存するときは上書きしません。同じ名前がすでにある場合は新しいファイルに番号を付け、保存した件数を 1 つの概要で表示します。

## Product features
ファイルをアップロードせずにタイムスタンプを付与 — 記録されるのは SHA-256 ダイジェストだけ
ファイルごとに PDF 証明書とオフラインで検証できる .beatproof 証明
多数のファイルやフォルダーごとまとめて付与
アプリに組み込まれた鍵で、ファイルと証明をオフライン検証
プライベートモード: 公開ログの自分用コピーで、何を確認したか誰にも知られない
内蔵の証人: 署名付きチェックポイント、独立したコピー、Bitcoin アンカー

暗号化された送付物はメール、メッセンジャー、USB メモリー、共有フォルダーで届けられる
弁護士、鑑定人、裁判所向けの証拠パッケージと PDF レポート
すべてのタイムスタンプと証明の状態を示す履歴
オプションの Tor モード
無料 — アカウント、広告、テレメトリーなし
オープンソース (Apache-2.0)
