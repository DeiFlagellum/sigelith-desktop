# Sigelith Desktop — zh-cn

## Short description
无需上传即可为文件盖戳，离线核验任何证明，关注公开日志的独立见证者——并带交付证明地交付文件。免费、无需账户、开源。

## Description
Sigelith Desktop 证明某个文件在某一时刻已经存在——而文件本身从不离开你的电脑。

为文件盖戳
把文件拖到窗口上。应用会在你的电脑上计算每个文件的 SHA-256 摘要，只把这个摘要发送到 Sigelith 公开日志。你会得到一份 PDF 证书和一个离线证明 .beatproof。

无需信任我们即可核验
拖入任意文件，即可查看它是否以及何时被盖戳。应用会用程序内置的密钥自行检查包含路径和签名。在隐私模式下，它会保存一份公开日志的副本，因此服务器永远不会知道你在检查哪个文件。

见证者
运行期间，应用会自行审计日志：签名的检查点、它们之间的链、GitHub、Internet Archive 和 Zenodo 上的副本，以及其中提到的比特币区块。任何不一致都会触发警报。

带交付证明地交付文件
接收方用自己的密钥（Windows Hello）确认收到，交付时刻记录在公开日志中。交付件在你们之间传递；Sigelith 服务器不保存任何东西。
对于没有验证工具的人（律师、鉴定人、法院）：用“验证证据…”打开证据并保存 PDF 报告——每项检查都用通俗的语言说明，并附有独立检查的方法。
如果交付物无法按提议打开，接收方的接受不产生效力。应用会指出这一点，并保存任何人都能重新计算的缺陷证明。

默认隐私
隐私模式会保存整个公开日志的副本（只有本来就公开的摘要），因此刷新证明永远不会让服务器知道哪一个是你的。

时间戳能证明什么
时间戳表明，字节完全相同的文件最迟在记录的时刻已经存在。它不能表明文件由谁创建，也不能表明其含义。 证明与完全相同的字节绑定。被编辑器重新保存或被即时通讯重新压缩的副本，摘要会不同——请把原件和证书一起保存。

Sigelith Desktop 免费且开源（Apache-2.0）。无需账户，没有广告，没有遥测。
支持英语、波兰语、德语、西班牙语、法语、俄语、土耳其语、日语、韩语、中文和阿拉伯语。

## What's new in this version
• 一次处理多个文件：为一批文件盖戳后，“PDF 证书”和“离线证明”按钮会为本批的每个文件分别保存证书或 .beatproof 证明，存到你选择的文件夹中。此前只会为最后一个文件保存。
• 历史记录：选中多个条目，即可为每个条目分别保存证书或证明。
• 保存多个文件时不会覆盖任何文件：如果名称已被占用，新文件会加上编号，并用一份摘要显示已保存的文件数量。

## Product features
无需上传即可为任何文件盖戳——只记录其 SHA-256 摘要
每个文件都有 PDF 证书和可离线核验的 .beatproof 证明
一次为多个文件或整个文件夹盖戳
用应用内置的密钥离线核验文件和证明
隐私模式：自有一份公开日志副本，没人知道你在核验什么
内置见证者：签名检查点、独立副本和比特币锚定
以接收方密钥和 Windows Hello 签名的交付证明
加密交付物可通过电子邮件、即时通讯、U 盘或共享文件夹传递
面向律师、鉴定人和法院的证据包与 PDF 报告
记录每次盖戳及其证明状态的历史
可选的 Tor 模式
免费——无需账户，无广告，无遥测
开源（Apache-2.0）
支持 11 种语言
