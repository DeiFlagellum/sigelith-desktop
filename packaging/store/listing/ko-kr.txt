# Sigelith Desktop — ko-kr

## Short description
파일을 업로드하지 않고 스탬프를 찍고, 어떤 증명이든 오프라인으로 검증하고, 공개 로그의 독립적인 증인을 지켜보고, 전달 증명과 함께 파일을 전달하세요. 무료, 계정 불필요, 오픈 소스.

## Description
Sigelith Desktop은 파일이 특정 시점에 존재했음을 증명합니다. 파일 자체는 컴퓨터 밖으로 나가지 않습니다.

파일에 스탬프 찍기
파일을 창으로 끌어 놓으세요. 앱은 내 컴퓨터에서 각 파일의 SHA-256 해시를 계산하고, Sigelith 공개 로그에는 그 해시만 보냅니다. PDF 인증서와 오프라인 증명 .beatproof를 받습니다.

우리를 믿지 않고 검증하기
아무 파일이나 끌어 놓으면 스탬프가 찍혔는지, 언제 찍혔는지 알 수 있습니다. 앱은 프로그램에 내장된 키로 포함 경로와 서명을 직접 확인합니다. 비공개 모드에서는 공개 로그의 자체 사본을 보관하므로, 서버는 어떤 파일을 확인하는지 결코 알 수 없습니다.

증인
앱은 실행 중에 로그를 스스로 감사합니다. 서명된 체크포인트, 그 사이의 체인, GitHub·Internet Archive·Zenodo의 사본, 그리고 그 안에 적힌 Bitcoin 블록까지. 불일치가 있으면 경보를 울립니다.

전달 증명과 함께 파일 전달하기
수신자는 자신의 키(Windows Hello)로 수령을 확인하고, 전달 시각은 공개 로그에 기록됩니다. 전달물은 두 사람 사이를 오가며, Sigelith 서버는 아무것도 보관하지 않습니다.
검증 도구가 없는 사람(변호사, 감정인, 법원)을 위해서는 증거 확인…으로 증거를 열고 PDF 보고서를 저장하세요. 모든 확인 항목이 쉬운 말로 담기고, 독립적으로 확인하는 방법도 함께 들어 있습니다.
전달물이 제안된 대로 열리지 않으면 수신자의 수락은 효력이 없습니다. 앱이 이를 알려 주고, 누구나 다시 계산할 수 있는 결함 증거를 저장합니다.

기본값은 비공개
비공개 모드는 공개 로그 전체(어차피 공개된 해시만)의 사본을 보관하므로, 증명을 새로 고쳐도 어느 것이 내 것인지 서버가 알 수 없습니다.

스탬프가 증명하는 것
스탬프는 정확히 이 바이트로 된 파일이 기록된 시각 이전에 존재했음을 보여 줍니다. 누가 파일을 만들었는지, 무엇을 의미하는지는 보여 주지 않습니다. 증명은 정확히 그 바이트에 묶여 있습니다. 편집기가 다시 저장했거나 메신저가 다시 압축한 사본은 해시가 다릅니다. 원본을 인증서와 함께 보관하세요.

Sigelith Desktop은 무료 오픈 소스입니다(Apache-2.0). 계정, 광고, 원격 측정이 없습니다.
영어, 폴란드어, 독일어, 스페인어, 프랑스어, 러시아어, 튀르키예어, 일본어, 한국어, 중국어, 아랍어로 제공됩니다.

## What's new in this version
• 여러 파일을 한 번에: 묶음에 스탬프를 찍은 뒤 [PDF 인증서]와 [오프라인 증명] 버튼은 묶음의 모든 파일마다 인증서 또는 .beatproof 증명을 선택한 폴더에 저장합니다. 지금까지는 마지막 파일만 저장되었습니다.
• 내역: 여러 항목을 선택하면 항목마다 인증서 또는 증명을 저장할 수 있습니다.
• 여러 파일을 저장할 때는 덮어쓰지 않습니다. 이름이 이미 있으면 새 파일에 번호를 붙이고, 저장된 파일 수를 하나의 요약으로 보여 줍니다.

## Product features
파일을 업로드하지 않고 스탬프 찍기 — 기록되는 것은 SHA-256 다이제스트뿐
파일마다 PDF 인증서와 오프라인으로 검증할 수 있는 .beatproof 증명
여러 파일이나 폴더 전체를 한 번에 스탬프
앱에 내장된 키로 파일과 증명을 오프라인 검증
비공개 모드: 공개 로그의 자체 사본으로, 무엇을 확인하는지 아무도 모름
내장 증인: 서명된 체크포인트, 독립 사본, Bitcoin 앵커
수신자의 키와 Windows Hello로 서명되는 전달 증명
암호화된 전달물은 이메일, 메신저, USB 메모리, 공유 폴더로 이동
변호사, 감정인, 법원을 위한 증거 패키지와 PDF 보고서
모든 스탬프와 증명 상태를 보여 주는 기록
선택형 Tor 모드
무료 — 계정, 광고, 원격 분석 없음
오픈 소스(Apache-2.0)
11개 언어 지원
