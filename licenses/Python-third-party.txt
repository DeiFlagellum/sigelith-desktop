Third-party software inside the Python (CPython 3.14.7) files
=============================================================

Python-PSF.txt next to this file is the LICENSE.txt of the Windows build of
CPython 3.14.7, unchanged.  Besides the Python license itself it carries the
notices of bzip2 (in _internal/_bz2.pyd), of libffi (_internal/libffi-8.dll,
which _internal/_ctypes.pyd uses), the Apache License 2.0 of OpenSSL
(_internal/libcrypto-3.dll and libssl-3.dll) and the terms for the Microsoft
Distributable Code (_internal/VCRUNTIME140.dll, VCRUNTIME140_1.dll).  Its
Zstandard and Tcl/Tk notices concern _zstd.pyd and the tkinter files of the
CPython release, and neither is in this package.

The CPython release compiles in more third-party code than that file names.
The documentation of the same release lists it under "Licenses and
Acknowledgements for Incorporated Software" (Doc/license.rst; installed with
CPython 3.14.7 as Doc/html/license.html, and published on
https://docs.python.org/3.14/license.html).  This file reproduces, verbatim,
the sections of that list that concern files in this package.  It adds the
notice of HACL*, which the list does not name, from the headers of the HACL*
sources of CPython 3.14.7 (Modules/_hacl), and the license of zlib-ng 2.2.4,
the zlib that the Windows build of CPython 3.14.7 compiles in.

  _internal/python314.dll
      Mersenne Twister, SipHash24, strtod and dtoa, zlib (zlib-ng 2.2.4),
      cfuhash, mimalloc, Global Unbounded Sequences, HACL* (the built-in
      MD5, SHA-1, SHA-2, SHA-3, BLAKE2 and HMAC of hashlib), Unicode
      Character Database
  _internal/unicodedata.pyd
      Unicode Character Database
  _internal/pyexpat.pyd
      Expat 2.8.2 (_internal/_elementtree.pyd uses it through pyexpat)
  _internal/_decimal.pyd
      libmpdec (mpdecimal 4.0.0)
  _internal/_asyncio.pyd and SigelithDesktop.exe
      asyncio
  SigelithDesktop.exe (the standard library in the archive inside it)
      http.cookies, xmlrpc.client, compression.zstd
  _internal/base_library.zip
      the uu codec (encodings.uu_codec)

_internal/_lzma.pyd contains liblzma from XZ Utils 5.2.5, which is in the
public domain and asks for no notice.  The sections of the list that are left
out concern code that is not in this package: the socket helpers of the WIDE
Project (not compiled into the Windows build of _socket.pyd), the test suite
(asynchat and asyncore, test_epoll, the W3C C14N test data), the trace module
and the kqueue interface of select, which does not exist on Windows.  The
OpenSSL and libffi sections repeat notices that Python-PSF.txt already
carries.
