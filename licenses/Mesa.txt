The Mesa 3D Graphics Library
============================

`_internal/PySide6/opengl32sw.dll` in this package is a software (CPU)
implementation of OpenGL built from Mesa 3D -- the "llvmpipe" Gallium driver.
The file is shipped as part of the Qt release; the build string inside it
reads "Mesa 11.2.2".  Qt loads it only when the machine has no usable OpenGL
driver of its own.
