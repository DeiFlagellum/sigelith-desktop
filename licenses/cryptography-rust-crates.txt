Rust crates compiled into cryptography's _rust.pyd
==================================================

`_internal/cryptography/hazmat/bindings/_rust.pyd` in this package is not
only cryptography's own code.  It is a statically linked Rust binary: the
crates below are compiled into it, and each carries its own permissive
license with its own attribution requirement.

The list is the complete dependency graph of cryptography 50.0.1, taken from
the Cargo.lock of the 50.0.1 release
(https://github.com/pyca/cryptography/blob/50.0.1/Cargo.lock, identical to
the Cargo.lock in the cryptography-50.0.1.tar.gz source distribution on
PyPI). The license of each crate is the license field of that exact version,
read from the Cargo.toml inside the crate itself (each crate file checked
against the checksum in Cargo.lock); it is the same field that crates.io
publishes for that version. The software bill of materials that the wheel
ships
(_internal/cryptography-50.0.1.dist-info/sboms/cryptography-rust.cyclonedx.json)
names the same 40 crates, with the same versions and licenses. Crate
versions read out of the shipped binary itself (asn1 0.24.1, base64 0.23.0,
itoa 1.0.18, once_cell 1.21.4, openssl 0.10.81, openssl-sys 0.9.117, pem
4.0.0, pyo3 0.29.0, pyo3-ffi 0.29.0) agree with that lock file.

Some of these are build-time only (procedural macros, build scripts,
probing helpers) and leave no code in the binary.  They are listed anyway:
an over-complete attribution costs a screen of text, an incomplete one costs
the notice requirement.

The OpenSSL that the `openssl-sys` crate links -- OpenSSL 4.0.2, a different
build from the OpenSSL 3.5.7 that comes with CPython -- is a separate
component in the NOTICE file.

The full texts of the licenses named below are next to this file:
Apache-2.0.txt covers "Apache-2.0" and the Apache half of every dual
license; the MIT text is reproduced at the end of this file; BSD-3-Clause is
reproduced in idna.txt and reportlab.txt; "Unicode-3.0" is reproduced in
Qt-third-party.txt, in the section on the Unicode Character Database and
Unicode CLDR.  self_cell is offered under "Apache-2.0 OR GPL-2.0-only"; it
is used here under Apache-2.0.
