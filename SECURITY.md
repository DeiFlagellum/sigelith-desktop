# Security policy

Please report a vulnerability in Sigelith Desktop or in the Sigelith service privately, by
e-mail to **kontakt@advena-partners.com** (English, German or Polish), as listed in
<https://sigelith.org/.well-known/security.txt>. Please do not open a public issue for it.

Fixes go into the current version only, which the Microsoft Store installs automatically.
What the program sends and why — only SHA-256 hashes, never files — is described in the
[README](README.md#privacy).
